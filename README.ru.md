# EasyServer

**Язык:** [English](README.md) · Русский

Арендуйте облачные серверы, управляйте ими из одного интерфейса и делайте удалённые сервисы доступными на собственном `localhost`.

```text
Арендовать сервер → запустить на нём приложение → Connect → 127.0.0.1:<local-port>
```

EasyServer оставляет специфичные для провайдера части там, где им и место: у Vast.ai остаётся marketplace, у Intelion.cloud — собственный конфигуратор серверов. После создания ресурса EasyServer даёт единое место для управления сервером и локального доступа к нему.

Основной интерфейс для человека — полноэкранный TUI в терминале:

```powershell
easyserver
```

CLI предназначен для скриптов, автоматизации и расширенного управления:

```powershell
easyserver --help
```

## Зачем EasyServer

- **Один рабочий процесс после аренды.** Запуск, остановка, перезапуск, удаление, просмотр и подключение не требуют каждый раз переключаться на модель конкретного провайдера.
- **Нативное для провайдера создание ресурсов.** Плагины сохраняют marketplace, образы, flavor, цены и параметры создания конкретного провайдера вместо попытки свести их к одной неполной универсальной форме.
- **Локальный доступ без публикации портов приложения наружу.** Удалённый сервис вроде `127.0.0.1:8188` может быть доступен локально как `127.0.0.1:54321`.
- **Безопасные интерактивные подтверждения.** Платные/разрушительные действия и первое доверие к SSH-хосту требуют явного подтверждения.
- **Провайдеры только по выбору пользователя.** Ядро устанавливается без плагинов провайдеров; добавляйте только нужные.

EasyServer управляет сервером как вычислительным ресурсом и границей подключения. Он **не** устанавливает и не настраивает приложения на арендованной машине.

## Установка и первый запуск

EasyServer `0.2.x` сейчас квалифицирован для **Windows 11 x64** с **Node.js 24.18.1**. Точные границы поддержки описаны в [Поддерживаемых платформах](docs/ru/supported-platforms.md).

Установите ядро CLI и один плагин провайдера:

```powershell
npm install --global @easyai101/easyserver
npm install --global @easyai101/easyserver-plugin-vastai
# или: npm install --global @easyai101/easyserver-plugin-intelion
```

Затем запустите:

```powershell
easyserver
```

В TUI:

1. Откройте **Settings & Support → Providers** и добавьте установленного провайдера.
2. Настройте его credential.
3. Выберите **Rent a server** и пройдите пошаговый сценарий провайдера.
4. Откройте сервер, выберите **Connect** и укажите порт приложения/сервиса, запущенного на сервере.
5. При первом подключении проверьте SSH fingerprint, после чего используйте локальный адрес, который покажет EasyServer.

Например, если ComfyUI слушает на сервере `127.0.0.1:8188`, EasyServer может открыть его локально по адресу:

```text
http://127.0.0.1:54321
```

ComfyUI здесь только пример: EasyServer перенаправляет произвольные TCP-сервисы и не управляет самим приложением.

Полный сценарий первого запуска находится в [руководстве Getting Started](docs/ru/getting-started.md).

## Поддерживаемые провайдеры

Для EasyServer `0.2.x` доступны first-party плагины:

- **Vast.ai** — поиск и аренда предложений marketplace, управление жизненным циклом и доступ по SSH. [Руководство по Vast.ai](docs/ru/providers/vastai.md)
- **Intelion.cloud** — каталог и конфигурация серверов, создание, управление жизненным циклом и доступ по SSH. [Руководство по Intelion.cloud](docs/ru/providers/intelion.md)

Сторонние провайдеры могут интегрироваться через публичный пакет `@easyai101/easyserver-plugin-sdk`. Начните с [руководства по созданию плагина провайдера](docs/ru/plugin-authoring.md).

## npm или переносимый ZIP

Пакеты npm — основной способ установки в экосистеме. Пользователи Windows также могут запускать ядро CLI из версионированного ZIP в GitHub Releases, не устанавливая core package глобально.

Переносимый ZIP по-прежнему требует Node.js и намеренно не содержит плагинов провайдеров. Проверка checksum и установка плагинов в нужный prefix описаны в [руководстве по установке из GitHub Releases](docs/ru/github-release-install.md).

## Пример CLI

Тот же базовый сценарий доступен без TUI. Создание ресурса остаётся специфичным для провайдера, а управление сервером и подключение после этого становятся общими:

```powershell
easyserver instances list
easyserver connect <instance-id> --port 8188
```

`connect` выводит локальный loopback-адрес и владеет им до завершения foreground-команды. Семантика портов, SSH trust, восстановление после ошибок и выбор метода подключения описаны в [руководстве по подключениям](docs/ru/connections.md).

Для подключений, которые должны пережить текущий терминал или восстановиться после перезапуска daemon, см. [Фоновые подключения](docs/ru/background-connections.md).
