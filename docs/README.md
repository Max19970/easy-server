# EasyCompute documentation

This directory is part of EasyCompute's public product surface.

Documentation kept here must be useful to at least one external audience: EasyCompute users, Provider Plugin authors, integrators, security reporters or contributors. Maintainer-only plans, continuation notes, internal issue mirrors, account-specific acceptance journals, reconnaissance scratch and agent instructions belong in the private sibling developer workspace instead of this repository.

Current public guides:

- [Provider Plugin authoring and operational safety](plugin-authoring-and-operational-safety.md)

Additional user, provider, release and compatibility documentation is added here as the public `0.1.0` release surface is finalized.
