# EasyServer 0.2.2

Дата версии: **2026-08-17**

EasyServer `0.2.2` — обратно совместимый distribution-релиз линии `0.2.x`. Главное изменение: теперь каждая release-qualified client platform получает полноценный portable-артефакт в GitHub Releases, а release automation требует полного покрытия всех поддерживаемых платформ до публикации релиза.

Миграция с `0.2.1` не требуется. Существующие корректные Local State, Secret References, CLI workflows и Provider Plugins линии `0.2.x`, объявляющие совместимость `^0.2.0`, остаются валидными.

Эта страница — историческая документация релиза. Для актуального использования начните с [Getting started](../getting-started.md) или [индекса документации](../README.md).

## Главное

### Portable GitHub Release теперь доступен для каждой квалифицированной платформы

Начиная с `0.2.2`, GitHub Releases публикуют проверенный portable-артефакт для каждого release-qualified client target:

- Windows 11 x64 — `easyserver-0.2.2-windows-x64.zip`;
- Ubuntu 24.04 x64 — `easyserver-0.2.2-linux-x64.tar.gz`;
- macOS 15 arm64 — `easyserver-0.2.2-macos-arm64.tar.gz`.

Общий manifest `easyserver-0.2.2-SHA256SUMS.txt` содержит SHA-256 для каждого portable-артефакта.

В bundle входят EasyServer CLI и production runtime dependencies, но намеренно не входят Node.js и Provider Plugins. Vast.ai и Intelion.cloud можно затем установить через npm непосредственно в распакованный portable-prefix.

Платформенные команды загрузки, проверки checksum, распаковки и установки Provider Plugins описаны в [Установке из GitHub Releases](../github-release-install.md).

### Каждый portable-артефакт собирается и проверяется на своей ОС

Release-target contract один раз задаёт поддерживаемую матрицу артефактов и используется одновременно CI и tag-driven публикацией. Каждый квалифицированный runner собирает и проверяет свой native bundle, вместо кросс-сборки всех архивов на одной системе.

Native artifact smoke проверяет:

- запуск launcher вне репозитория;
- точный вывод release version через `--version`;
- работоспособность `--help`;
- корректную работу свежего bundle без настроенных Provider Plugins;
- возможность установить Vast.ai и Intelion.cloud в распакованный portable-prefix и загрузить их из него.

### Неполное покрытие платформ теперь блокирует релиз

Release automation рассматривает portable artifact coverage как обязательный инвариант: у каждой квалифицированной платформы должен быть ровно один определённый формат артефакта, а финальная публикация требует полного ожидаемого набора файлов до создания GitHub Release.

Отдельные тесты также подтверждают, что CI и release workflow продолжают строить свои matrix из единого authoritative release-target contract. Это не позволяет будущему изменению support matrix незаметно разойтись с набором публикуемых assets.

### После публикации проверяются уже реальные публичные assets

После создания GitHub Release native platform jobs скачивают настоящий опубликованный артефакт и checksum manifest и проверяют уже публичную distribution surface, а не только pre-publication build outputs.

Проверка включает SHA-256 и свежий запуск из внешней директории на каждой квалифицированной платформе.

### Windows release validation устойчивее к нагрузке хоста

Windows release gate больше не зависит от короткой wall-clock гонки при доказательстве того, что Secret Store выполняется вне Local State lock. Regression теперь напрямую проверяет сам lock-инвариант.

Temporary SSH credential ownership также не запускает PowerShell повторно после того, как identity текущего процесса уже успешно подтверждена. Identity кешируется только после успешного стабильного OS probe; scavenging старых credential owners по-прежнему заново проверяет PID и process identity перед удалением, сохраняя fail-closed защиту от PID reuse.

## Набор пакетов и совместимость

В релиз входят:

- `@easyai101/easyserver-plugin-sdk@0.2.2`;
- `@easyai101/easyserver@0.2.2`;
- `@easyai101/easyserver-plugin-vastai@0.2.2`;
- `@easyai101/easyserver-plugin-intelion@0.2.2`.

Compatibility ranges пакетов и Provider Plugins намеренно остаются `^0.2.0`. Таким образом `0.2.2` остаётся внутри существующей линии совместимости `0.2.x` и не требует обновлять плагины или пользовательские конфигурации только из-за patch-релиза.

Корректный Local State линии `0.2.x` остаётся поддерживаемым; миграции state в этом релизе нет.

## Установка этой исторической версии

### npm

```text
npm install --global @easyai101/easyserver@0.2.2
npm install --global @easyai101/easyserver-plugin-vastai@0.2.2
# или
npm install --global @easyai101/easyserver-plugin-intelion@0.2.2
```

### GitHub Release

Release `v0.2.2` публикует:

```text
easyserver-0.2.2-windows-x64.zip
easyserver-0.2.2-linux-x64.tar.gz
easyserver-0.2.2-macos-arm64.tar.gz
easyserver-0.2.2-SHA256SUMS.txt
```

Перед распаковкой проверьте checksum нужного артефакта. Точные команды для каждой платформы приведены в [Установке из GitHub Releases](../github-release-install.md).

## Release environment

Квалифицированный runtime этого релиза:

- Node.js `24.18.1`;
- npm `11.16.0` для npm/package и установки Provider Plugins.

Квалифицированные client targets:

- Windows 11 x64 с Windows Credential Manager и Windows OpenSSH Client;
- Ubuntu 24.04 x64 с рабочим Linux Secret Store path и системным OpenSSH;
- macOS 15 arm64 с macOS Keychain и системным OpenSSH.

На Linux keyring integration сначала пытается использовать D-Bus Secret Service и при его недоступности переключается на Linux kernel keyring через keyutils. Границы headless и неквалифицированных окружений описаны в [Поддерживаемых платформах](../supported-platforms.md).
