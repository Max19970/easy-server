# Документация EasyServer

**Язык:** [English](../README.md) · Русский

Начните с задачи, которую хотите решить. Документация намеренно становится технически плотнее по мере перехода от первого запуска к автоматизации, расширению, совместимости и безопасности.

Английская документация остаётся каноническим источником публичных контрактов. Правила поддержки переводов и добавления новых языков описаны в [Локализации документации](localization.md).

## С чего начать

- [Getting Started](getting-started.md) — установить EasyServer, добавить провайдера, арендовать сервер и открыть первый сервис на `localhost`.
- [Интерактивный TUI](tui.md) — навигация по основному интерфейсу, управление серверами, настройка провайдеров, восстановление после ошибок подключения и accessibility modes.
- [Поддерживаемые платформы](supported-platforms.md) — актуальные границы поддержки ОС, Node.js, npm, OpenSSH и Secret Store.

## Подключение к серверам

- [Подключение к удалённому сервису](connections.md) — foreground-подключения, удалённый и локальный порты, доверие к SSH-хосту при первом использовании, типичные ошибки и расширенный выбор метода подключения.
- [Фоновые подключения](background-connections.md) — managed daemon, фоновые Sessions, сохранённые connection intents, idempotency, перезапуск и восстановление.

## Работа с провайдером

- [Vast.ai](providers/vastai.md) — подготовка аккаунта, поиск/аренда на marketplace, жизненный цикл, требования к подключению и освобождение платных ресурсов.
- [Intelion.cloud](providers/intelion.md) — подготовка аккаунта, конфигурация/создание сервера, жизненный цикл, подключение и освобождение платных ресурсов.

Пакеты провайдеров подключаются явно. Чистая установка EasyServer не содержит плагинов провайдеров, пока вы сами не установите и не добавите нужный.

## Установка и эксплуатация EasyServer

- [Установка из GitHub Releases](github-release-install.md) — проверить и запустить переносимый ZIP для Windows, а затем при необходимости добавить плагины именно в эту распакованную установку.
- [Жизненный цикл пакета](package-lifecycle.md) — совместимые обновления, переустановка, отсутствующие плагины, удаление и полная очистка.
- [Поддержка и сопровождение](support-and-maintenance.md) — куда сообщать об ошибках, какие данные помогают при разборе и что проект поддерживает сейчас.

## Автоматизация и интеграция

- [Машинно-читаемый вывод CLI](cli-json.md) — версионированный envelope `--json`, exit semantics, данные provider commands и non-interactive сценарий SSH host trust.
- [Версионирование и совместимость](versioning-and-compatibility.md) — публичные гарантии для линий `0.x`, Plugin SDK, Local State и документированного поведения CLI.

Встроенная справка по командам доступна прямо в продукте:

```powershell
easyserver --help
easyserver instances --help
easyserver connect --help
```

Provider-specific деревья команд также публикуют вложенный help, если установленный плагин предоставляет соответствующий declarative contribution.
