# EasyServer 0.1.0

EasyServer `0.1.0` is the first public release of a provider-independent CLI for acquiring, managing and locally accessing rented compute.

Provider-specific acquisition stays in separately installed Provider Plugins. Once a resource exists, EasyServer gives it a shared Compute Instance model for inventory, lifecycle actions and local Endpoint access without forcing providers into one lossy creation API.

## Highlights

- First-party Provider Plugins for **Vast.ai** and **Intelion.cloud**.
- Shared instance inventory and lifecycle operations across providers.
- Generic local TCP Endpoints over SSH-backed provider access.
- Foreground connections and daemon-owned persistent Connection Sessions.
- Explicit SSH host-key trust on first use; changed trusted keys fail closed.
- Provider credentials stored through the OS-backed Secret Store rather than ordinary Local State.
- Public `@easyai101/easyserver-plugin-sdk` package for third-party Provider Plugins.
- Minimal core installation: **no Provider Plugin is bundled or enabled by default**.

## Install

EasyServer supports two CLI distribution paths on Windows 11 x64.

### npm

```powershell
npm install --global @easyai101/easyserver
```

Provider Plugins are opt-in packages:

- [`@easyai101/easyserver-plugin-vastai`](https://www.npmjs.com/package/@easyai101/easyserver-plugin-vastai)
- [`@easyai101/easyserver-plugin-intelion`](https://www.npmjs.com/package/@easyai101/easyserver-plugin-intelion)

The public extension API is published as [`@easyai101/easyserver-plugin-sdk`](https://www.npmjs.com/package/@easyai101/easyserver-plugin-sdk).

### GitHub Release ZIP

Download and verify:

- `easyserver-0.1.0-windows-x64.zip`
- `easyserver-0.1.0-SHA256SUMS.txt`

The ZIP contains the core CLI only and requires Node.js `24.18.1` on `PATH`. It does not bundle Node.js or Provider Plugins. See [Install from GitHub Releases](../github-release-install.md) for checksum, extraction and prefix-aware Provider Plugin installation instructions.

## Supported platform and runtime

The qualified `0.1.0` support target is **Windows 11 x64** with:

- Node.js `24.18.1`;
- npm `11.16.0` for npm-based installation and Provider Plugin package installation;
- Windows OpenSSH Client (`ssh` and `ssh-keyscan`) for SSH-backed access.

Linux and macOS are not qualified support targets for `0.1.0` yet. This is a support boundary, not a claim that the code is known to be incompatible there.

## Important limitations

- EasyServer is a compute/access control plane, not a workload orchestrator. It does not install or manage applications such as ComfyUI for you.
- EasyServer exposes local TCP Endpoints; `0.1.0` does not provide HTTP path routing, a VPN or a general reverse-proxy product.
- Provider billing semantics remain provider-specific. A stopped allocation can still have cost or reservation implications; use the provider-supported destructive lifecycle operation when you intend to release a resource.
- Provider Plugins execute as trusted in-process code and are not sandboxed.
- For Vast.ai SSH access in `0.1.0`, the private key corresponding to the account-level SSH public key must be discoverable through a standard OpenSSH identity file or `ssh-agent`; EasyServer does not use the user's `~/.ssh/config` in its managed SSH path.
