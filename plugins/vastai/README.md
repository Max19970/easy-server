# @easycompute/plugin-vastai

Opt-in EasyCompute Provider Plugin for Vast.ai compute.

## Install and register

Install EasyCompute separately, then install only the provider you want:

```sh
npm install --global @easycompute/plugin-vastai
easycompute plugins add @easycompute/plugin-vastai
```

This package does not install Intelion.cloud or any other Provider Plugin.

After registration, configure the plugin credential through EasyCompute rather than placing provider API keys in repository files or command arguments.

Documentation and source: https://github.com/Max19970/easy-compute
